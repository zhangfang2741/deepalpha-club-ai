# DeepAlphaBaZi App 产品页面设计

**日期**：2026-09-05
**范围**：MVP — 产品页面结构与信息架构（不含具体 API 契约 / Swift 工程细节，留给后续实施计划）
**产品形态**：iOS 原生 App，独立于 deepalpha.club 现有前端

## 1. 产品定位

**核心组合**：八字（底层引擎，免费引流） + AI 对话（辅助问答，非独立主界面） + 紫微斗数（订阅高级功能）。

**决策记录（brainstorming 过程中的关键调整）**：
- 最初设想中"生肖作为获客入口"在讨论中被否决——生肖运势赛道太拥挤、同质化严重（公众号/小程序/短视频已经饱和），作为独立获客入口很难突围，因此从产品范围中**彻底移除**。
- 替代的免费拉新钩子：**免费简版八字报告**——用户填生辰后立即得到一份免费的基础排盘 + 简要解读，深度解读和大运流年展开是付费点。
- AI 对话不做成独立主 Tab，而是嵌入在报告详情页里的常驻"问 AI"入口，符合"报告为主、对话辅助"的定位。
- 商业模式：**订阅制**（月/季/年），付费墙分两层——八字的"深度解读/大运流年展开"是订阅点之一，紫微斗数整体是订阅专区，AI 对话额度也随订阅解锁。
- MVP 严格只做八字报告 + 紫微报告 + AI 问答三项，不做合婚、摸骨、生肖测试等其他命理功能，也不预留相关扩展入口。

## 2. 信息架构

底部 3 个 Tab：

```
[ 八字 ]   [ 紫微斗数 ]   [ 我的 ]
```

- **八字**：免费引流主战场，承载每日可更新的内容（今日运势），维持打开频次。
- **紫微斗数**：订阅专区，整体锁在付费墙后，用命盘缩略图 + 权益清单展示价值。
- **我的**：会员状态、订阅管理、通知设置、隐私/客服。

AI 对话**不占用 Tab 位**，从八字 / 紫微报告详情页底部的"💬 问问 AI 这代表什么"入口呼出，作为悬浮聊天面板。这样两个命理系统共用同一套 AI 对话组件。

## 3. 页面详情

### 3.1 八字 Tab

**新用户态（未排盘）**：
- 引导文案 + 插画
- 表单：出生日期 / 出生时间（可选"不确定"）/ 出生地点
- CTA：「生成我的免费八字报告」

**已排盘用户态（日常首页）**：
- 四柱卡片：年柱/月柱/日柱/时柱 + 五行分布小图（免费）
- 今日运势一句话点评 + 宜忌（免费，每日更新，是维持打开频次的关键内容）
- 子入口（顶部分段）：概览 / 大运流年 / 深度解读
  - 概览：免费
  - 大运流年详细展开：付费墙
  - 深度解读（性格/事业/财运/婚姻长文分析）：付费墙
- 页面底部常驻「💬 问问 AI 这代表什么」

### 3.2 紫微斗数 Tab

**未订阅态**：
- 命盘缩略图模糊/打码预览（十二宫轮廓可见，星曜隐藏）——用"能看到形状但看不清内容"传递价值感，而非空白页
- 解锁后可见内容清单（十二宫完整星曜排布 / 命宫身宫详细解读 / 大限流年运势）
- CTA：「订阅解锁紫微斗数 · ¥XX/月」

**已订阅态**：
- 十二宫命盘图（可点击每宫查看星曜详情）
- 子入口：命宫解读 / 大限流年 / 十二宫详解
- 同样的底部常驻「💬 问问 AI 这代表什么」

紫微斗数**没有免费层**——不同于八字的"免费概览+付费深度"分层，紫微整体归属订阅权益，付费墙边界更清晰，方便订阅转化率埋点。

### 3.3 问 AI 悬浮聊天面板

从报告详情页底部呼出，覆盖在当前页面上：

- 顶部上下文提示条：明确当前聊的是哪份报告的哪个板块（如"正在聊：你的八字 · 日柱解读"），让 AI 回答有的放矢
- 2 个"猜你想问"快捷问题（降低输入门槛，如"今年适合跳槽吗" / "婚姻运势如何"）
- 输入框 + 对话气泡列表
- 额度提示：免费用户每日限次（如 3 次），订阅用户不限或大幅提高额度——这是订阅的核心卖点之一

### 3.4 我的 Tab

- 头像 + 昵称 + 会员状态徽章
- 「订阅管理 / 升级会员」
- 通知设置（每日运势推送开关）
- 隐私政策 / 关于 / 客服

保持精简，不做家人命盘管理等 MVP 范围外功能。

## 4. 核心用户流程

```
首次打开 App
  └─→ 八字 Tab：零门槛浏览引导页（无需登录）
       └─→ 填生辰（日期/时间/地点）
            └─→ 生成免费八字报告（四柱 + 五行 + 今日运势）
                 ├─→ 想看大运流年展开 / 深度解读长文 → 订阅付费墙
                 ├─→ 点击「问 AI」→ 悬浮聊天面板（免费限次）
                 └─→ 切到「紫微斗数」Tab → 模糊命盘预览 → 订阅付费墙
                      └─→ 订阅后：完整十二宫命盘 + 大限流年 + 无限 AI 问答额度
```

## 5. 技术架构（高层，细节留待实施计划）

- **iOS App**：新建 Xcode 工程 `DeepAlphaBaZi`，放在 `ios/` 目录下，沿用 `ios/DeepAlphaChan` 的工程结构与约定（MVVM + Service 分层）。
- **排盘引擎位置**：干支历法 / 五行 / 大运流年 / 紫微十二宫排盘计算放在后端，新建 `app/services/bazi/` 与 `app/services/ziwei/`，通过 REST API（`/api/v1/bazi/*`、`/api/v1/ziwei/*`）暴露给 iOS 端，iOS 端只做展示，不做排盘计算。
- **AI 解读/对话**：复用现有 `app/services/llm/` 的 `llm_service.call()`（多供应商 + 重试 + fallback），不新建独立的 LLM 调用路径。
- **订阅**：iOS 端走 StoreKit，后端需要一个订阅状态同步/校验的接口（具体设计留给实施计划）。

具体的 API 契约、数据库模型（`BaziChart` / `ZiweiChart` 等）、Swift 工程目录结构、排盘算法的实现细节，本设计文档不展开，作为下一步 `writing-plans` 或专门的后端设计 spec 的输入。

## 6. MVP 范围边界（明确排除）

- 不做生肖相关的任何功能（运势、配对、测试）
- 不做合婚 / 摸骨 / 塔罗 / 黄历等其他命理功能，也不预留入口
- 不做家人/朋友命盘管理
- AI 对话不做成独立主 Tab

## 7. 验收标准（页面层面）

- [ ] 新用户可在无需登录的情况下，通过填写生辰立即获得一份免费八字报告
- [ ] 免费报告展示四柱 + 五行分布 + 今日运势；「大运流年」展开与「深度解读」需订阅才能查看完整内容
- [ ] 紫微斗数 Tab 未订阅时展示模糊命盘 + 权益清单 + 订阅 CTA；订阅后展示完整十二宫命盘
- [ ] 八字与紫微的报告详情页底部均有「问 AI」常驻入口，点击后呼出带上下文提示条的悬浮聊天面板
- [ ] AI 对话面板展示"今日剩余次数"（免费用户），订阅用户不受此限制
- [ ] 「我的」Tab 可查看会员状态、管理订阅、开关每日运势推送通知
- [ ] 3 个 Tab 之间的信息架构清晰，不出现生肖相关 UI 残留
