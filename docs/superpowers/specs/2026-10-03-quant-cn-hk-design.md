### 1.1 已知的数据坑（有测试守护）
- **港股报表金额一律是人民币**：东财把美元 / 港元 / 欧元申报的公司按期末汇率折成人民币（汇丰、中芯比值 ≈ 7.03 = USD/CNY，
  中电 ≈ 0.90 = HKD/CNY），人民币申报的保持原值；报告清单里的 `CURRENCY` 是**原始申报币种**，主要指标表的 `CURRENCY=HKD` 不可信。
  所以港股统一折成**港元**（股价币种）再算：报表 × CNY→HKD；经济通预测按表头币种（美仙 / 分 / 港仙；表头为空时用申报币种）× X→HKD。
- 报表是**累计口径**（A 股一季 / 半年 / 三季 / 年报；港股多为半年 + 年报，少数按季）。换算成单季：每个字段在同一财年内
  按「相邻两个已知累计点之差、平均摊到其间各季」（`cnhk/reports.to_quarters`）。这样 TTM、同比、3 年复合、上一完整财年合计
  都是精确的；只有单季拆分是近似值（不展示）。A 股一季报 / 三季报常不披露现金流量表补充资料（折旧摊销）→ 缺失季度沿用最近一季的折旧摊销（只影响 EBITDA）。
- A 股一般企业 EBIT = 利润总额 + 利息费用（财务费用中的利息支出，缺失时用财务费用）；港股 EBIT = 除税前溢利 + 融资成本。金融类不算 EBIT / EBITDA / EV。

## 2. 样本与行业
- **A 股**：总市值前 1800（剔除 ST / 退市整理），相当于沪深300 + 中证500 + 中证1000 的规模。
- **港股**：港股通标的 ∪ 总市值 ≥ 20 亿港元（约 1000 只；只用港股通时能源仅 18 只，低于 20 只的最小样本）。
- 行业：东财行业（A 股 128 个、港股 31 个）**静态映射**到 GICS 11 个一级行业（`cnhk/sectors.py`，有测试保证全部映射），
  少数大型港股按 GICS 实际归属覆盖（腾讯 → 通信服务、阿里 / 美团 / 京东 → 可选消费 等）。
- 样本外股票：按当天的行业分布现算（与美股一致），Redis 缓存 1 天。

## 3. 指标差异（`markets.MarketProfile.unsupported`，不在列表里显示、也不计入维度分母）
- A 股没有 EBITDA / EBIT 一致预期：去掉 `ebitda_fwd`、`ebit_fwd`、`ev_ebitda_fwd`、`ev_ebit_fwd`。
- 港股没有营收 / EBITDA / EBIT 一致预期：再去掉 `ps_fwd`、`ev_sales_fwd`、`rev_fwd`、`rev_fy1_90d`。
- EPS 修正：用自有快照（A 股、港股均从本期上线日起积累，30 天后部分启用、90 天全部启用）；美股的外部趋势过渡不适用。
- 护城河：依赖美股 10-K，A 股 / 港股不显示（`moat=null`，App 已有隐藏逻辑）。

## 4. 调度与额度
- A 股：工作日 UTC 09:00（北京 17:00）；港股：工作日 UTC 10:00。与美股相同的 Redis 短锁 + 心跳，冷启动自举（无结果或方法版本变化时）。
- A 股报表：历史报告期不变，只在首次（或每 30 天一次全量）拉 17 个报告期；平时只刷新仍在披露窗口内（报告期后 125 天内）的期次，约 100 次请求。
- 港股报表：逐只，只在出现新报告期、无快照或快照超过 90 天时重拉。
- 所有东财 / 经济通请求经同一个礼貌限速客户端（并发 3、请求间隔 ≥ 0.25 秒、失败重试），不走 `.env` 代理（`trust_env=False`）。

## 5. 分析师评级（`/analyst-upgrades/overview/{symbol}?market=cn|hk`）
- 五档用中文券商通行档位：**买入 / 增持 / 中性 / 减持 / 卖出**，响应 `ratings.bucket_labels` 下发档位名（美股不下发，App 沿用原档位）。
  旧版 App 不认识 `bucket_labels`，会把「买入」画成「强力买入」——所以只有请求带 `bucket_labels=1`（新版 App）才返回 A 股 / 港股数据，
  旧版仍得到「暂只支持美股」。
- A 股：评级分布按月重建——每个月末，取近 6 个月内每家机构最近一次评级计数（东财研报列表）；最近评级变动 = 逐篇研报
  （本次 / 上次评级 → 首次覆盖 / 上调 / 下调 / 维持）；目标价：近 6 个月内有目标价的研报 ≥ 3 篇才显示。
- 港股：经济通每家券商只有最新评级与目标价——显示当前分布、目标价（近 6 个月更新的券商）、最新评级列表（无历史趋势）。
- 业绩预期 vs 实际（季度 EPS 意外）A 股 / 港股无季度一致预期，不显示。
- 评级原文只引述；档位归并表（`overview_cnhk.RATING_TIERS`）未知评级不计入分布、原样显示在列表里。
