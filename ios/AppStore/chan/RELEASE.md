## 🔴 提交前必做（容易漏的两项）

### 1. 重建审核演示账号

`SUBMIT.md` 末尾要求上架后删除 `appreview@deepalpha.club`（弱密码账号，留着是风险）。
**如果当时删了，这次必须重建**，否则审核员登不进去，必被 2.1 打回。

```
appreview@deepalpha.club
AppReview2026
```

建完自己登一次，确认能看到分析结果页。

### 2. 真机验证（模拟器测不了或测不准的）

本版改动集中在手势、离屏渲染和本地化，这三类都得在真机上看：

- [ ] **保存到相册**：首次点会弹系统授权框（新权限，1.0 没有），确认文案语言正确、允许后相册里确实有图
- [ ] **分享长图**：图层开关那一排在图里（此前会整排消失）、截图与品牌脚**左右边缘对齐**、底部免责条完整不被裁
- [ ] **MACD 手势**：详情页和全屏页，手指落在 MACD 上能左右拖、能双指缩放，主副图不错开
- [ ] **图标名与语言**：本版把开发区域从 `zh_CN` 改成了 `en`。中文系统下确认桌面图标仍是「缠论」；
      把系统语言换成英文（或地区换成非中国大陆）确认界面为英文、图标名为 DeepAlpha
- [ ] **全屏转屏**：进全屏转横屏 → 退出后回到竖屏（回归项，失败会卡横屏）
- [ ] **订阅**：沙盒账号购买 + 恢复购买（回归项）

## 提交流程

1. **合并到 master**，确认 master 上 `xcodebuild` 通过后再打包，避免发出去的包不在主干上
2. **Xcode → Product → Archive**
   - scheme 选 DeepAlphaChan，设备选 Any iOS Device
   - ⚠️ Archive 前把 Edit Scheme → Run → Options 的 **StoreKit Configuration 置为 None**，
     否则本地测试配置可能影响验证（发布包本身已排除该文件）
3. **Distribute App → App Store Connect → Upload**，等 5–15 分钟处理完
4. **ASC → App → 左侧「+ 版本」→ 填 1.1**
   - 「此版本新增内容」：粘贴 `store-listing.md` 第五节 1.1 的中英文案，**两个语言各填一次**
   - 构建版本：选 1.1 (2)
   - 截图：现有 6 张仍然有效（核心界面未变），不换也能过；想展示分享功能可另加
   - 描述、关键词、推广文本：**不用动**（1.0 已通过，动了要重审）
5. **审核信息**：演示账号照旧填；备注里加一句说明新权限——

   ```
   本版新增「保存分析图到相册」功能，会申请相册写入权限（仅 add-only）。
   路径：分析任意标的 → 结果页右上角分享按钮 → 保存到相册。
   ```

6. 发布方式建议仍选 **手动发布**，通过后自己验一遍再放出
7. 点「提交以供审核」

> 更新版本的审核通常比首审快，24 小时内居多。
